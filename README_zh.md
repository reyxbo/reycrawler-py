# reycrawler

**reycrawler** 是一个用于网络爬取的 Python 方法集成包。

提供对百度、豆瓣、新浪、今日头条、微博等网站的爬取方法，并通过模块化的方式集成不同网站的数据爬取能力。

同时提供基于浏览器拟人控制的页面爬取方法，可通过模拟浏览器行为获取页面 HTML 文本，从而在部分场景下绕过网站的反爬机制。

适用于网站数据采集、信息获取以及网络爬虫等场景。

## 特性

* 提供网络爬虫相关方法
* 集成多个知名网站的爬取方法
* 支持百度系网站数据爬取
* 支持豆瓣网站数据爬取
* 支持新浪网站数据爬取
* 支持今日头条网站数据爬取
* 支持微博网站数据爬取
* 提供其它网站的数据爬取方法
* 支持基于浏览器的拟人化页面爬取
* 支持通过浏览器获取页面 HTML 文本
* 支持基于数据库轮询任务的浏览器爬取任务
* 提供统一的方法导出接口
* 模块化设计，可按需使用不同网站的爬取方法

---

## 安装

要求 **Python 3.12 或更高版本**。

```bash
pip install reycrawler
```

# 模块

reycrawler 按功能及目标网站划分为多个模块，各模块负责不同的网站爬取及基础功能。

## `rall` — All import methods

**统一导出模块。**

提供 reycrawler 所有模块方法的便捷导出，可以通过该模块集中导入框架提供的功能，减少从多个模块分别导入的代码。

---

## `rbaidu` — Crawl Baidu website methods

**百度网站爬取模块。**

提供百度系网站的数据爬取方法。

主要包括：

* 百家号网站数据爬取
* 百度翻译网站数据爬取
* 其它百度系网站数据爬取

---

## `rbase` — Base methods

**基础方法模块。**

提供其它爬虫模块共用的基础方法和公共依赖。

主要用于支持其它模块的运行，并提供通用的基础功能。

---

## `rbrowser` — Browser methods

**浏览器爬取模块。**

通过浏览器拟人控制的方式爬取网页 HTML 文本，从而在部分场景下实现绕过网站反爬机制。

基于数据库轮询任务提供浏览器爬取任务，使其它程序可以通过数据库任务的方式调用浏览器爬取能力。

主要提供：

* 浏览器拟人化控制
* 网页 HTML 文本获取
* 反爬场景下的浏览器爬取
* 基于数据库轮询的爬取任务
* 浏览器爬取任务集成方法

---

## `rdouban` — Crawl Douban website methods

**豆瓣网站爬取模块。**

提供豆瓣网站的数据爬取方法。

主要包括：

* 影视剧排行榜数据爬取
* 影视剧详细数据爬取
* 其它豆瓣网站数据爬取

---

## `rother` — Crawl other website methods

**其它网站爬取模块。**

提供其它网站的数据爬取方法。

主要包括：

* 中国农历日期信息爬取
* 其它网站数据爬取

---

## `rsina` — Crawl Sina website methods

**新浪网站爬取模块。**

提供新浪网站的数据爬取方法。

主要包括：

* 证券市场搜索结果爬取
* 股票详细数据爬取
* 其它新浪网站数据爬取

---

## `rtoutiao` — Crawl Toutiao website methods

**今日头条网站爬取模块。**

提供今日头条网站的数据爬取方法。

主要包括：

* 热点新闻数据爬取
* 其它今日头条网站数据爬取

---

## `rweibo` — Crawl Weibo website methods

**微博网站爬取模块。**

提供微博网站的数据爬取方法。

主要包括：

* 热点新闻数据爬取
* 其它微博网站数据爬取
